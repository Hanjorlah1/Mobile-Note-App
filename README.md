# Scribble - Mobile Note App

A simple and clean mobile-first note-taking app built with HTML, CSS, and JavaScript.  
Create, edit, delete, and search notes with data saved in the browser using localStorage.

## Live Demo
[View Live Demo](https://hanjorlah1.github.io/Mobile-Note-App/)

## Features
- Create new notes
- Edit existing notes
- Delete notes
- Search notes in real-time
- Dark / Light theme toggle
- Notes sorted by newest first
- Empty state when no notes exist
- Data persists using localStorage
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5 (for basic styling)
- localStorage

## What I Learned
- Working with localStorage to save and retrieve data
- DOM manipulation (creating and removing elements)
- Handling user events (click, input, etc.)
- Implementing search functionality
- Managing application state
- Creating a clean empty state UI
